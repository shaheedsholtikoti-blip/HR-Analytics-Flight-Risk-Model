# 🧠 HR Strategy Terminal: Predictive Flight Risk & Financial Impact

**Author:** Shaheed S Holtikoti  
**Tech Stack:** `Python` | `scikit-learn` | `pandas` | `numpy` | `ipywidgets`

## 📌 Project Overview
This project bridges the gap between HR analytics and corporate finance. It is an interactive, machine learning-driven dashboard that not only predicts the probability of an employee leaving the company but also calculates the **Financial Value at Risk (VaR)** if they depart.

## ⚙️ Key Features
* **Random Forest Predictive Engine:** Trained on a synthetic dataset of 2,500 employees to identify attrition patterns across 9 distinct variables (including salary, commute, and performance rating).
* **Strategic ROI Calculation:** Dynamically calculates replacement costs (1.5x - 2.5x base salary) weighted by flight probability to quantify financial risk for executives.
* **Interactive UI:** Built entirely within Jupyter Notebooks using `ipywidgets` to create a Fortune-500 style executive terminal.
